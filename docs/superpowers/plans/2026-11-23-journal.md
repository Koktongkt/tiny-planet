# Journal Book Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the spiral-notebook Journal (J) with the leather journal book: five ribbon bookmarks (Quests, People, Recipes | Discoveries, Memories), sub-tabs, and list/detail pages fed by the live save, plus the three save additions and Bag/bench links into Recipes.

**Architecture:** Pure page-data builders in `src/systems/journalPages.js` (unit-tested, no DOM) turn `G.s` + game tables into plain rows for each page. A React book in `src/ui/journal/book/` draws the painted art (1448x1086, scaled to fit like the Bag satchel) with the bookmarks, sub-tabs and the five pages on top. `PanelsC.jsx` shows the new book when it fits the screen and keeps the old notebook as the small-screen fallback, the way the Bag falls back to its list.

**Tech Stack:** React 18, plain CSS, Vite; `node --test` unit tests; Playwright smoke tests.

**Spec:** `docs/superpowers/specs/2026-11-23-journal-design.md` (mock: `ui-mocks/a/journal.html`, which is the visual reference for every page and for the bookmark CSS).

## Global Constraints

- Bookmarks: Quests `#e2654c→#b8402e`, People `#f3c25a→#d4922a`, Recipes `#7ab4cf→#4f89a8` on the left group (art x 160–652); Discoveries `#9cc75c→#679a34`, Memories `#ea9a92→#c86a66` on the right group (art x 796–1262); bottoms on the page edge at art y 238; no counts on bookmarks, gold dot = something new.
- Sub-tabs: Recipes Tools · Food · Decor · Keepsakes (Tools also holds recipe cats `Garden` and `Unlock`); Discoveries Fish · Forage · Relics; Memories Photos · Firsts.
- Never spoil: unfound = silhouette "? ? ?", unmet villager = "???", unlearned recipe = "???", gift shelves show only items given to that villager.
- Board notes not yet accepted are never listed one by one: one "New notes on the board" card, and nothing can be accepted from the Journal.
- Old saves load unchanged: every new field is optional and starts empty; `SAVE_VERSION` does not change.
- Keep the Recipe Book panel, its HUD button and the C key working exactly as today.
- Unit tests run with `node --test tests/unit/*.test.mjs` (the `test:unit` script passes a folder, which Node 22 rejects; fix the script to the glob in Task 1).
